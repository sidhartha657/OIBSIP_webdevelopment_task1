# Responsive Landing Page

## Overview

This project is a modern and responsive Landing Page developed as part of the AICTE OASIS INFOBYTE SIP Internship (Level 1 - Task 1). The website is designed using HTML5 and CSS3 with a focus on clean design, responsiveness, and user experience.

## Features

* Responsive Design
* Modern Navigation Bar
* Hero Section
* Statistics Section
* Services Section
* About Section
* Testimonials Section
* Call-to-Action Section
* Attractive Animations and Hover Effects
* Modern Footer

## Technologies Used

* HTML5
* CSS3

## Project Structure

├── index.html
├── style.css
└── README.md

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
